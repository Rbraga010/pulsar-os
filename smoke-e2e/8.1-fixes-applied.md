## Fix 1 🔴 — vazamento DATABASE_URL em validate.sh

**Arquivo:** `installer/smoke/validate.sh` linha 87.

**Antes:**
```bash
DB_URL="${DATABASE_URL:-postgresql://pulsarh:pulsarh_secure_pass_2026@172.19.0.2:5432/pulsarh_war_room}"
```

**Depois:**
```bash
DB_URL="${DATABASE_URL:-$(grep -E '^DATABASE_URL=' /tenant/.env.local 2>/dev/null | cut -d= -f2- | tr -d '"' | tr -d "'")}"
if [ -z "${DB_URL}" ]; then
  warn "DATABASE_URL nao definido. Configure em /tenant/.env.local. Pulando check agent_logs."
  DB_URL=""
fi
```

Severidade: CRITICA (credencial real PulsarH ia pro cliente).
