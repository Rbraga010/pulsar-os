# SKILL · DEV · SITES (placeholder MVP)

## STATUS · ESQUELETO INICIAL

Skill base · sera expandida conforme demandas reais aparecerem nas instalacoes lojistas.

## STACK PADRAO (MVP)
- Next.js 14+ · app router · TypeScript estrito
- Tailwind CSS · shadcn/ui (componentes basicos)
- Vercel · deploy automatico via GitHub
- DNS Cloudflare (opcional)

## TEMPLATE LANDING PAGE LOJA CLARO
Estrutura minima recomendada:
1. **Hero** · logo + endereco + WhatsApp + foto da fachada
2. **Plano destaque** · 1 plano da semana com call to action
3. **Servicos** · lista do que a loja oferece (pre, pos, NET, TV)
4. **Sobre** · historia da loja + atendimento humanizado
5. **Localizacao** · mapa Google embedded + horario
6. **Contato** · WhatsApp + telefone + Instagram

## TEMPLATE CRM SIMPLES
- Cadastro cliente (nome, CPF, telefone, endereco, plano atual)
- Status atendimento (novo, qualificando, proposta enviada, fechado, perdido)
- Historico de interacoes
- Lembretes de follow-up
